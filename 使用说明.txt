精读课件 · CreativeLearner
使用说明 
==========

【怎么打开】
双击 大学英语课件/index.html 即可（推荐 Chrome / Edge）。整个文件夹需要保持在一起，
audio 子文件夹里是本课件的录音，删掉会没有声音。

【首页目录】
打开后默认是「目录首页」：顶部是 CreativeLearner 标志与全书统计（6 个单元 / 18 篇课文 /
262 段音频 / 220 个词条 / 104 组 627 道练习），下面是第三册、第四册各三个单元的卡片，
点任意卡片进入该单元；左侧栏「目录首页」按钮可随时回到这一页。

【三个开关（右上角，可同时使用，状态会自动记住）】
1. 课文 · 英汉对照 —— 默认只显示英文原文；打开后，每一段英文下方出现对应的中文译文（逐段对照）。
   课文后附的列表、表格、小标题也有中文，一并显示。
2. 练习 · 中文对照 —— 默认只显示原题；打开后，题干、选项、以及选词填空的整句译文与词义提示都会出现。
3. 练习 · 答案 —— 默认隐藏；打开后，每题下方出现参考答案（黄底区域）。
   判断题点 T / F、选择题点 A/B/C/D 可先自测，答案打开后自动标出对错（绿=正确，红=错误）。

【快捷键】
Z 课文英汉对照    A 练习答案    X 练习中文    空格 播放/暂停
右上角 A− / A+ 可调整正文字号。

【音频】
- 每篇课文标题下有两个按钮：
  「整篇连播」= 播放整篇录音（一个文件，段落之间无缝），当前段落自动高亮并跟随滚动；
  「逐段连播」= 按段依次播放，也自动跟随滚动。
- 鼠标移到任意段落，右侧出现 ▶ 按钮，可单段反复听。
- 音频取自随书课件自带的录音目录（Reading 1_1.mp3、Reading 2_1.mp3、Text_1.mp3 …，
  其中 _0 为整篇），已统一转码为 48kbps 单声道。18 篇课文全部有音频，逐段对齐无缺。

【重点词汇朗读】
- 每个「重点词汇」区块标题右侧有「连续朗读」按钮：点击后用微软 Ryan 语音
  （Microsoft Ryan Online (Natural)）依次朗读该表全部单词——**只读词形，不读释义、词性、例句**；
  当前单词所在卡片会高亮并自动滚动跟随；再点一次（按钮变为「停止朗读」）即可停止。
- 直接单击任意一个单词，也能朗读该词。
- 在线自然语音由 Edge / Chrome 从微软云端获取，需联网；把鼠标停在按钮上可看到当前实际使用的语音名。
- 切换单元会自动停止朗读；开始朗读时也会暂停课文录音，避免混音。

【页面顺序（按 PPT 原顺序排列）】
单元导览 → 主课文 → 重点词汇 → 课后练习 → 阅读1 → 本篇词汇 → 阅读1练习 → 阅读2 → 本篇词汇 → 阅读2练习 → 综合技能

【课后练习结构（共 104 组 / 627 题，已按学生用书逐项核对）】
一、课文部分（顺序与学生用书一致）
  1. 课文结构分析 Text Organization（填表：段落划分 + 各部分大意）
  2. 课文细读 Digging into detail（问答，标注所在段落）
  3. 难句理解 Understanding difficult sentences（A/B 选择，每单元 5 题）
  4. 重点词汇 1.1 选词填空 / 1.2 替换划线部分 / 1.3 仿例完成句子
  5. 构词法 Word Formation（合成词配对与运用，B3U5）
  6. 语法运用 Usage（enough、sort of / kind of、倒装、分词作定语、as 作连词等）
  7. 句型 Sentence Patterns 3.1 / 3.2
  8. 综合练习 4.1 完形填空、4.2 段落汉译英
二、阅读1部分：判断正误 / 段落定位 / 英译汉
三、阅读2部分：阅读理解（问答或选择）/ 选词填空 / 汉译英
四、综合技能：视听说填空（B3U2、B3U3）
其中「英译中」这一组不做中文对照——中文译文本身就是答案，打开「答案」即可对照。

【内容来源】
- 课文、译文、词汇释义、练习答案：来自《全新版大学进阶英语 综合教程》（第二版）第三、四册
  教师手册（docx）。
- 练习题干、判断题、段落定位题、选择题：来自配套 PPT 课件与学生用书 PDF。
  已按学生用书逐单元核对：18 篇课文的段落数与顺序全部一致；补齐了原先缺失的
  「课文结构分析」与「难句理解」（各单元 5 题，答案取自教师手册）。
- Book 3 Unit 3 的主课文英文在原 docx 中只到第 10 段，已按 PPT 全文补全为 17 段。
- 选词填空一组的空由程序依据答案自动挖空，个别小题若原句含并列说法，可能保留一处提示。
