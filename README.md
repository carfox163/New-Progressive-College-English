
## 功能

- **英汉对照**：课文逐段对照；练习题干与说明也可切换中文
- **答案开关**：课后练习默认不显示答案，按键显示
- **课文音频**：每段单独播放，也可整篇连续播放
- **重点词汇朗读**：词汇表「连续朗读」按钮用微软 Ryan 语音依次朗读单词；单击单词单独发音
- **题干点读**：练习区的英文题干、完形句子、参考答案均可点击朗读（再点一次停止）；
  每组练习另有「依次朗读」按钮
- **首页目录**：六个单元卡片式导航与统计概览
- **页面顺序**：单元导览 → 主课文 → 词汇 → 课后练习 → 阅读 1 → 词汇 → 练习 → 阅读 2 → 词汇 → 练习

## 使用

本地：双击 `index.html`（推荐 Chrome / Edge），`audio` 文件夹需与 `index.html` 放在一起。
在线：在本仓库 Settings → Pages 中选择分支根目录即可生成访问链接。

练习总量：104 组 · 627 题，全部配有参考答案；18 篇课文 · 262 段音频。
